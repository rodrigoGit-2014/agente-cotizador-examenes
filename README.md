# agente-cotizador-examenes

La rama `ChristopherV1` contiene el programa desarrollado por Christopher para continuar el trabajo en equipo.

El proyecto ejecutable está en [`cotizador-opencode/cotizador-examenes`](cotizador-opencode/cotizador-examenes/README.md). Su README describe la instalación, la configuración de OpenAI y Redis, la carga de datos y la ejecución.

Incluye el cotizador con llamadas simuladas, consulta de catálogo desde Redis, memoria durante la sesión, datos de demostración, notebook y pruebas. La validación completa y la evidencia final del notebook están pendientes; véanse los casos y scripts en `validacion/`.

Cada integrante debe crear su propio entorno virtual y configurar un `.env` a partir de `.env.example`. Las credenciales y el entorno virtual no se incluyen en el repositorio.
